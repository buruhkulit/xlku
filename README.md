# Cara menjalankan dengan TERMUX
1. Update & Upgrade Termux
```
apt update && apt full-upgrade
```
2. Install Git
```
pkg install git
```
3. Install Python
```
pkg install python
```
4. Install Python Pillow
```
apt install python-pillow
```
5. Clone this repo
```
git clone https://github.com/buruhkulit/xlku
```
6. Open the folder
```
cd xlku
```
7. Setup
```
bash setup.sh
```
8. Install Requirements
```
pip install -r requirements.txt
```
